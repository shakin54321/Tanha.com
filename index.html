Project Overview

This is a personal front-end birthday experience built as a single HTML project. The chapters, animations, verification screen, password gate, and visual effects run inside the browser.

Privacy & Data

The page does not intentionally send names, messages, password values, or verification results to a project server. Any browser storage used by the intro stays under the browser's local storage controls.

Cookies & Local Storage

The cookie buttons are an experience setting rather than a tracking system. The page may remember an intro option using localStorage, and that browser data can be cleared at any time.

Password & Access

The password gate is a private presentation layer. Because this is client-side HTML, it is not server-grade security and should not protect highly sensitive information.

Human Verification

The verification screen is a lightweight local interaction. After one click, it runs an animated browser-side check for a few seconds before opening the next step. It is not a replacement for professional anti-bot services.

External Media

Some chapter images or GIFs may come from external URLs. Those resources can make network requests and their availability depends on the hosting service. Local assets such as img.png, itt.png, loading-photo.png, and music.mp3 can be placed beside this HTML when used.

Browser Compatibility

The experience is designed for modern mobile and desktop browsers. Animations may behave differently when reduced-motion, battery-saving, or older browser settings are enabled.

Hosting & Sharing

This project can be hosted as a normal static webpage. Anyone who receives the HTML can inspect or modify its front-end source, so private personal details should not be placed directly into the code.

Responsible Use

Share the page respectfully and only include content you are comfortable making part of the webpage source. External media should be used with appropriate permission where required.
